# Hornbound

A js13k game jam entry 2026

Theme: Unicorns and Rainbows

You can play the game at: https://labrat.mobi/games/hornbound/

Game developed using: [karlib](https://www.npmjs.com/package/@goldenratio/karlib)

## Requirements

- [Node.js >=22.18.0](https://nodejs.org/en/download)

## Local Developement

```console
npm i
npm run dev
```

## Packing for js13k

- Run `npm run build:js13k`, to build game and create `dist.zip` for distribution
